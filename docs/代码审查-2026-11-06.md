# 数据看板代码审查与改版

审查基线：3c444f5。重点检查 2268f92..3c444f5 的完整改动，以及看板渲染、容器布局、HTTP 数据入口和统计聚合调用链。以下问题均已在本次工作区修复。

1. **[P2] 解除看板对列表滚动布局的依赖 — client.js:357、4710（基线行号）**

   窄屏规则主动把五张图堆成自然高度，并且看板仍位于带页尾的任务列表滚动容器内。结果是窄屏必然滚动，短窗口还会压缩图表或需要滚动才能查看完整内容，与无滚动条要求不符。改为独立占满工作区；宽高充足时展示五图，其余尺寸用选择器查看每张完整图表。

2. **[P2] 为环形图覆盖工具图标尺寸 — client.js:4468（基线行号）**

   环形图设置了 108px 的 SVG 属性，但根节点下通用 SVG CSS 将宽高覆盖为 20px，中心总数与圆环错位。新增环形图专用宽高规则，并取消工具图标的圆端描边继承。

3. **[P2] 从进行阶段中排除未中标项目 — lib/board.js:201（基线行号）**

   阶段过滤只排除了已中标项目，未中标项目既计入原阶段，又计入未中标分组。一条招采阶段且未中标的记录会被统计成两条。现在两个收口状态均独立计数；该样例断言总数为 1。

另修复自定义周期只修改一个端点时缺少另一个参数、被后端回退为本月的问题；该问题不作为本次提交范围的新回归列入上面的审查发现。
